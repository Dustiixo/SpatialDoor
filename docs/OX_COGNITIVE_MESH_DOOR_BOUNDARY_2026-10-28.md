# SpatialDoor / DOOR — cognitive mesh integration boundary
**Date:** 2026-10-28. **Status:** Planning-only. Current GitHub baseline contains a minimal README and license. Full native DOOR/MATRIX source authority has **not** been verified here.

## Program authority
DOOR owns the continuous calibrated 3D work space and native spatial renderer. Its simultaneous pixel points, volumetric ASCII, hex networks and geometry are layers in **one** space; camera, depth, occlusion and persistent IDs are measurable. ORBITAL/oxGraphing retains editor ownership and MATRIX retains its independent renderer lineage. A visible edge or avatar gesture never grants permission to run tools.

## Local cognitive agent
- PASSIVE: report renderer health, frame resource estimates, selected scene/object version, waiting batons.
- ACTIVE: interpret an explicitly scoped spatial proposal, reason from real geometry and telemetry, prepare a proposed edit within a review sandbox.
- RELAY: send an evidence-linked request to owner-specified Build Factory, or return a blocked/needs-input receipt. Release resources after durable acknowledgment.
The core inference engine may be shared with IXO, but the renderer must remain responsive when that engine is offline.

4. Demonstrate one non-destructive GREMLIN/IXO spatial request becomes a durable proposal, not an unapproved scene mutation.
